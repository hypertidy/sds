# Tasmania DEM (2m)

by MRT 2021

## Usage

``` r
tas_dem(vsicurl = TRUE)
```

## Arguments

- vsicurl:

  prefix with vsicurl or not

## Value

data source name for Tasmania 2m DEM

## Examples

``` r
tas_dem()
#> [1] "/vsicurl/https://s3.us-west-2.amazonaws.com/us-west-2.opendata.source.coop/alexgleith/tasmania-dem-2m/Tasmania_Statewide_2m_DEM_14-08-2021.tif"
```
