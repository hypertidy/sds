# sds: Spatial Data Sources

Descriptions of spatial data sources that can be read directly with or
without download. Most sources are readable by 'GDAL' software. There
are functions for imagery, elevation, and a variety of easily accessible
data streams including image tile servers, links to online files, and
geographic data services.
